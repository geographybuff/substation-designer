# Substation Designer

A game about designing rural electric substations, built on the engineering guidance in
**USDA Rural Utilities Service (RUS) Bulletin 1724E-300, *Design Guide for Rural Substations*** (June 2001).

You lay out a substation yard, connect the equipment, choose ratings, shield it from lightning, design
the ground grid, and then energize it to see whether it is safe, reliable and on budget. Design checks
cite the section, table or page of the bulletin they come from, so every rule in the game can be traced
back to the source.

> **Status:** in active development. See [CHANGELOG.md](CHANGELOG.md) and the
> [Releases page](https://github.com/geographybuff/substation-designer/releases) for playable builds.
